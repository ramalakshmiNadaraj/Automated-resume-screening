# Automated Resume Screening System

## About the Project

The Automated Resume Screening System is a project designed to help simplify the initial resume screening process using Natural Language Processing (NLP).
The system aims to analyze resume content and identify relevant information based on job requirements.

## Objectives

* Reduce the time required for initial resume screening.
* Extract relevant information from resumes.
* Compare resume content with job-related requirements.
* Help organize resumes for further evaluation.

## Technologies Used

* Python
* Natural Language Processing (NLP)
* Flask 
* HTML and CSS
* Machine learning libraries

## Features

* Resume text extraction
* Resume keyword analysis
* Job description matching
* Resume ranking or scoring

## Installation and Setup

1. Clone this repository.
2. Open the project folder.
3. Create and activate a Python virtual environment.
4. Install the dependencies listed in `requirements.txt`.
5. Follow the project's instructions to run the application.

## Future Improvements

* Improve resume matching accuracy.
* Support additional resume formats.
* Enhance the user interface.
* Add more detailed screening reports.

## Disclaimer

This project is intended to assist with initial resume review. Automated scores should not be treated as the sole basis for hiring decisions.
